# IRITOT: Personal Finance Tracker

<!-- flutter run -d chrome -->

A sleek, 100% offline, privacy-first personal finance app built with Flutter.

## Features
- **Sleek Neo-Fintech Design:** Dark obsidian palette with emerald & cyber cyan accents.
- **Dynamic Growth Orbit Splash Screen:** Fluid 60+ FPS animations.
- **100% Offline Local Storage:** Stored securely directly on device.
- **Account & Security:** Local credentials with 5-minute inactivity auto-lock protection.
- **Multi-language Support:** English (default) and Bahasa Indonesia.
- **Automated Cloud iOS Build:** GitHub Actions workflow to compile iOS `.ipa`.
